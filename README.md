# uORocketry Avionics Software Monorepo

Welcome to the uORocketry's avionics software monorepo. This is where we house all of our of our projects, new and old.

## Monorepo Structure
This monorepo is grouped by project, with directories containing relevant firmware and software to each subproject.

### NGAP
Software & Firmware related to the NGAP Era of boards can be found in `NGAP/*`. 

See [NGAP/](./NGAP/) for more details.

### Phoenix_ERA
Software & Firmware related to the Phoenix Era of boards can be found in `Phoenix_ERA/*`. 

See [Phoenix_ERA/](./Phoenix_ERA/).
