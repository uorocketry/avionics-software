# RGS Web

The web frontend for the uORocketry Ground Station.

## Getting Started

Install [Bun](https://bun.sh/), then run these commands from `apps/ground-station-web`:

Then, run the following

```bash
bun install --frozen-lockfile
bun run dev
```

The Vite development server prints its local URL when it starts. Use `deployments/ground-station/compose.yaml` when the complete backend is required.
