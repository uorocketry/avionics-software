# Ground Station Tools

Development, setup, and field-diagnostics utilities that are not part of the default deployment:

- `manual-command-dispatcher`: direct MAVLink command TUI
- `virtual-serial`: pseudo-terminal serial simulator
- `remote-test`: gamepad input diagnostics
- `sbg-test`: SBG device readers and build helpers
- `ssh-setup`: local-network SSH provisioning
- `tenna-manual` and `tenna-setup`: antenna hardware utilities
- `scripts`: workstation setup and port inspection helpers
